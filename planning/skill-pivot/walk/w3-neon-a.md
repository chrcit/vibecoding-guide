## Curriculum review

### What landed well
1. **"Work first, guide in the margin" felt genuinely natural on both runs.** The retired nurse walked out of L1 with a genuinely useful village-hall tea plan (zero-waste routine, gluten/dairy safety, two-Sunday tin ledger, rainy-day stress test) AND an intuitive mental model of the loop, text-as-steering, snapshots, and data privacy — without ever feeling lectured or drowned in jargon.
2. **Pass-3 fixes held up almost across the board.** `H1` (exact global-install wording), `H2` (literal 3-line fresh-thread tail), `H4` (writing only the exact shown `AGENTS.md` text), `H5` (returning session stays concise without going quiet), `H6` (pausing before a growing second job while answering tiny one-offs directly), `H7` (honest Supervised read answer), `H8` (zero out-of-project writes), `H9` (clean missing-identity git recovery + tracked vs new files), and `H10` (preview-before-render exact match) all worked cleanly on `antigravity/gemini-4-neon-medium`.
3. **L3's rhythm for a `some` learner was crisp and practical.** Honoring `AGENTS.md` ("short explanations; table when comparing things") turned every aside and comparison into scannable tables instead of essays.

### Gaps and concrete skill fixes
1. **Fix `F8` in `skills/agentic-guide/mechanisms/window.md:16` (medium priority):**
   L3 proved causally why `F8` still leaks on Antigravity: in a returning session (`L3`), the agent reads `window.md` when a second job starts, not `text.md`. Because `window.md:16` (`some`) still says unconditionally *"Starting fresh is cheap: `AGENTS.md` carries what should survive"* (and `window.md:50` says *"put what matters in `AGENTS.md`"*), the model faithfully repeated that false promise on Turn 4 — and immediately corrected itself on Turn 7 the moment it read `text.md`. Qualifying `window.md:16` and `window.md:50` ("where your harness auto-loads `AGENTS.md`; otherwise mention it or read it explicitly") closes the leak across every lesson.
2. **Tighten `H3` enforcement on comparison-table delta columns (`skills/agentic-guide/mechanisms/loop.md`):**
   Even when the model ran `python3` to compute every base SQL metric in L3 T2/T3, it still added a derived `Paid − Email` difference column (`−20.0 pp`, `+$13.33`, `+$50.00 (2.0×)`) by hand in HTML without either computing those deltas in Python or noting them as hand-written. Calling out comparison-table difference/delta columns explicitly in `loop.md` will catch this last H3 corner case.
3. **Resolve the `H4` + unconfirmed-level timing pinch in `skills/agentic-guide/mechanisms/text.md` (*Persistence*):**
   In L1 T5, the agent showed the proposed `AGENTS.md` note without `Level: plain` and asked both *"save this?"* and *"is non-coder right?"* in one turn. When the nurse confirmed both on T6, obeying `H4` strictly meant writing only the exact shown lines — leaving `AGENTS.md` with no `Level: plain` line at all by the end of L1. Either ask to confirm the level one turn earlier (or let the agent re-show the updated note with `Level: plain (confirmed)` before writing when both happen together).
4. **Three quick polish items (`moves.md`, `window.md`):**
   - **Inline page contrast (`moves.md`):** Remind the recipe not to override `-foreground` inside `--accent`/`--primary` highlight rows with semantic colours like `--success` (green `+£6.95` on blue `--accent` failed contrast in L1 T2/T3/T5), and note that larger user-requested body fonts (`18px`) can nudge 375px narrow-width height past `2000px` (L1 T9: `2154px`).
   - **Handover vs H2 line 3 (`window.md`):** In L1 Handover, placing `"To get the guide there, start your message with $agentic-guide."` right under the plain fresh-thread opener slightly conflicts with testing `AGENTS.md` without `$agentic-guide`; clarify that line 3 is for calling the guide back *later*, not for the plain handover test.
   - **L1 T5 `Try:` repetition (`text.md`):** When the agent has already drafted and shown the `AGENTS.md` note in the same reply, avoid a `Try:` prompt telling the learner to ask for that exact same draft-and-show step.
