# Walkthrough pass 1: bug fixes

The rule is the stable rule: fix only what is wrong or what a learner trips on. No new sections, files or features, and no renames. Every fix is the smallest edit that solves it, and most go into the mechanism files and `moves.md`, not `SKILL.md`. `SKILL.md` is at its budget of about 2,000 tokens, so anything added there must be paid for by tightening nearby text. Findings are numbered by their line in [inbox.jsonl](inbox.jsonl).

## The Antigravity experiment (F8)

In a fresh fixture (`walk/fixture.sh f8-<name>`), find out what Antigravity puts in a new thread's context before the first tool call:

1. With `AGENTS.md` only.
2. With `GEMINI.md` added.
3. With `.agent/rules/<x>.md` (or whatever its docs name), if that exists.

Each file carries a distinct harmless marker rule, for example "end every reply with 🌿". Start a plain thread on `--provider antigravity --model gemini-4-neon-medium` with a task that doesn't mention the files, then ask it to list which files were already in its context and which it read with a tool. Record the results in `walk/f8-antigravity.md`. Then write the skill text from what you observed, not from memory, and label it observed on today's date.
