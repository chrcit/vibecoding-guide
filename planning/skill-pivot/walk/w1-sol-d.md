## Curriculum review

- **L1.** A precise result from one sentence gave the engineer something real to challenge. The jump from two internal gap ranges to expected sequence endpoints gave the check a purpose. Five cases with expected versus actual turned the learner's judgment into a repeatable request, and the unhinted fresh thread reused it. Count actual tool invocations when teaching the loop. Ask for a concrete style preference at the first natural opening and show the proposed project rule immediately. The fresh-thread test demonstrated style and check continuity, while the fresh thread's scratchpad write showed that guide-only boundaries did not carry over. The learner would reuse “Run it on five different inputs, including one that should break it” and “Show me the output that proves it works.”
- **L3.** The mug note made shared context visible on the learner's own work. That was the moment for a single explanation about what the conversation contains. The six-month plan then gave the learner a real choice about separating the jobs. The fresh index's different soup season demonstrated the other half of the mechanism. It could recover an omitted detail on request by reading the source conversation. Teach that reference at the first point where there are two conversations and a practical reason to look back. The learner would reuse “Summarise what the next thread needs to know from this one, in one paragraph,” with the blackberry rule named, or “Look at my earlier recipe conversation and tell me what we decided about the soup.”
- **L5.** The synthetic CSV supported all three locations in the lesson. The file was on the agent host, printed rows reached the provider through command output, and the conversation could be rewound independently of the file. The tracked edit and untracked new file made Git's scope visible. The learner would reuse “What did you change on my computer today? Group it into files, commands and anything that left this machine” and “Make me invented data with the same columns and kinds of values as mine, and build the method on that first.” Treat individual read approvals as harness-dependent from the first explanation.
- **Coverage.** These runs exercised the assigned Claude Code harness. No artificial compaction was forced, no real data was submitted, and no application permission setting was changed. The CLI could request a thread lookup by title but could not test sidebar clicks, keyboard shortcuts, autocomplete or drag. Tests of level inference from R or formulas would require a fresh learner without a seeded level.
