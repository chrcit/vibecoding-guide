## Cross-cutting curriculum themes

### 1. Returning sessions: what is broken vs what should be moved
Returning sessions are the #1 structural weak spot in [`SKILL.md`](/skills/agentic-guide/SKILL.md). Across **12 independent returning runs**, agents failed in two opposite ways:
- **Over-firing first-session boilerplate** (10 runs: `w1-neon-c-L2`, `w1-sol-d-L3`, `w1-sol-d-L5`, `w2-opus-a-L3`, `w2-opus-a-L5`, `w2-opus-b-L2`, `w2-opus-b-L4`, `w2-opus-b-L6`, `w2-opus-b-L6b`, `w2-sol-b-L6`): repeating the Reply 2 block, re-announcing a confirmed level (twice falsely claiming it was guessed from writing), or appending `"Anything you'd change?"`. Fix Pass 2 (`G1`) cut this dramatically in later Pass 2 runs (`w2-neon-b`, `w2-neon-c`, `w2-sol-a`, `w2-sol-b`), and Fix Pass 3 (`H5`) tightened it further (still unverified).
- **Under-firing asides** (2 runs across Claude + Codex: `w1-neon-a-L5`, `w2-neon-a-L3`): treating a returning session like a `quiet` session — zero `Guide ·` asides or `Try:` lines across all 8 turns of `w2-neon-a-L3`.
- **Broken snapshot anchor** (3 runs: `w1-opus-a-L3`, `w2-opus-a-L5`, `w2-sol-a-L5`): `SKILL.md` L20 anchors the snapshot offer to *"after reply 2"*, which does not exist in a returning session.

**Root cause:** `SKILL.md` is structured around a 450-word *The first session* script, with returning sessions described only by negation inside *Setup 2*. Moving returning-session rules into a dedicated 4-line *Returning sessions* section (instead of asking the model to mentally subtract pieces of *The first session*) is the cleanest `next version` refactor.

### 2. Level calibration (`plain` / `some` / `deep`)
- **What works:** Automatic level inference from technical signals (`CSS`, `SQL`, `R`, formulas → `some` even when the learner says *"I don't write code"*, verified in `w2-sol-a-L1` T2 and `w1-sol-c-L4` T2) and plain-level relabelling of `figures/layers.html` (`"The program / Its actions"`, no counts) landed consistently.
- **What leaks at `plain`:** Two bits of skill wording leak technical jargon into `plain` replies: `"model picker"` in the permission line (`SKILL.md` L19; 2 runs: `w1-opus-a-L1`, `w2-opus-a-L3`) and raw `AGENTS.md` in `window.md` *Try* (`"apart from what AGENTS.md already says"`; 2 runs: `w1-neon-c-L6`, `w2-neon-b-L4`).
- **What is missing at `deep`:** `world.md` **deep** lacks shell-vs-file-tool reach and tool `stdout`/`stderr` egress (2 runs: `w1-opus-a-L5`, `w2-neon-c-L5`); `loop.md` **deep** lacks the self-written checker blind spot (3 runs across `plain`+`deep`).

### 3. Harness differences (Claude Code vs Codex vs Antigravity)
- **Antigravity (`AGENTS.md` non-autoloading):** Confirmed in **5 Antigravity runs** (`w1-opus-c-L2`, `w1-sol-c-L2`, `w1-opus-c-L4`, `w1-neon-c-L4`, `w2-neon-c-L5`; `w1-neon-c-L2` only worked because the model voluntarily read `AGENTS.md`). The skill now avoids lying about autoloading, but the L1/L2 persistence handover still lands as a confirmed failure rather than teaching a workaround (`@AGENTS.md` or *"read AGENTS.md first"*).
- **Codex (quietness + pre-tool commentary):** On the 5 completed Codex runs, Codex followed explicit formatting/theme/safety rules reliably, but emitted visible pre-tool commentary bubbles before Reply 2 (2 runs: `w2-neon-a-L1`, `w2-sol-a-L1`) and went completely silent on asides in a returning session (1 run: `w2-neon-a-L3`). Because Codex has **0 done runs** on L2, L4, and L6, its behaviour on `text.md`, `loop.md`, and `moves.md` thread orchestration is untested.
- **Claude Code:** Strongest teaching cadence and rich `deep` outputs, but most prone to over-talking in returning sessions (`G1`/`H5`), slipping into auto-memory (`G3`, fixed), and publishing artifacts in unguided plain threads (`G2`, fixed).

### 4. Safety & data boundaries
- **What holds:** The four *Where data goes* sentences (`F5`/`G4`), refusing to guess employer/VPN visibility, never demonstrating reach outside the project (`F3`/`G3`), and stopping cleanly on missing Git identity without inventing an author (`F12`/`G6`) held across every Pass 2 run that tested them.
- **What is still missing:**
  - `world.md` *Side effects* does not list *"publishing a page or shareable link"* (caught in `w2-opus-a-L3` T11; currently mentioned only inside `window.md` Handover 3).
  - Tool `stdout`/`stderr` egress on local scripts (`w1-opus-a-L5` T4, `w2-neon-c-L5` T4).
  - Permission-mode inheritance on agent-launched parallel threads (`w2-neon-b-L6` T5, single-run observation).
  - Guide-only guardrails (e.g., no `/tmp` scratchpads) not following the learner into plain threads (`w1-sol-d-L1` T9, single-run observation).

### 5. Checking & verification
The biggest curriculum upgrade surfaced by the walkthroughs is a paired principle across `loop.md`, `text.md`, and `moves.md`:
1. **Maker = checker blind spot** (3 runs: `w1-opus-c-L4`, `w2-neon-b-L4`, `w2-sol-b-L4`): an agent's self-written check only tests rules the agent already thought of; the learner's job is supplying expected answers and small real-world counterexamples before scaling to N trials.
2. **Concrete, testable rules survive `AGENTS.md`; vague preferences drift** (4 runs: `w1-neon-a-L1`, `w2-neon-a-L1`, `w2-opus-a-L1`, `w2-sol-b-L2`): saved rules need to be agent-actionable (not offline human checklists), general (not task-specific numbers), and verifiable in one reply.

## What must not change

Strongest `works` patterns validated repeatedly across levels and harnesses — preserve these verbatim in any edit:

1. **Work-first opening & one reversible step past the bare ask (L1 Turns 1–2):** 3–5 line opening with no UI tour, followed by a real inline result with one reversible value-add (assumptions box, interactive controls, honest "What it does not do" list). Runs: `w1-opus-a-L1` T2, `w1-neon-a-L1` T2, `w1-sol-d-L1` T1–T2, `w2-neon-a-L1` T2, `w2-opus-a-L1` T2, `w2-sol-a-L1` T1–T2.
2. **Computed-vs-written separation & honest "stopped because it chose to" (L1/L4):** Naming the exact tool call that computed numbers vs text written by hand, plus tying *"why did it stop?"* to the model returning text without a tool call. Runs: `w1-opus-c-L4` T3, `w1-sol-c-L4` T3, `w2-opus-b-L4` T2–T3/T8, `w2-sol-b-L4` T3/T7, `w2-opus-a-L1` T9 (refused to fake missing `restic`).
